# PSVR2_OpenXR_Eye_Tracking
OpenXR-based Eye-tracking for PSVR 2 on PC / SteamVR. 

Calibration isn't finished yet. WIP but coming (2 solutions are possible).

These API layers rely on a THIRD PARTY closed-source and as-yet unreleased DLL, and I used the framework provided by mbucchia here (for other HMDs):

https://github.com/mbucchia/_ARCHIVE_OpenXR-Eye-Trackers
